The range

Best of N rolls

The best of N independent rolls is below a score with probability F(score)N, so the whole curve of “how good should my best be by now” is exact. RNGdle is one roll a day, so N rolls is N days.

Badge index

Rarity follows a badge's EP exactly as rngdle scores it: Common < 1,000 ≤ Uncommon < 10,000 ≤ Rare < 100,000 ≤ Epic < 1,000,000 ≤ Anomaly < 10,000,000 ≤ Mythic. Families: when a number earns several badges from one family, only the highest-EP one scores; the rest are shown but add 0 EP. “of numbers” is rngdle's own figure for the share of rolls that earn the badge. Examples are the three lowest numbers that earn it.
