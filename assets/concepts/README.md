# Logo concepts

Three alternative directions for RNGdle Tools:

- **Reels**: mechanical number windows, vermilion and condensed italic lettering.
- **Rare form**: an acid-yellow collectible ticket with expressive serif lettering.
- **Signal**: an electric-blue segmented R, coral accent and broad monospace lettering.

Each directory contains transparent light/dark SVG headers and standalone marks.
Lettering is outlined; labels use system monospace. These are design studies.
The active README and site icons use the existing teal grid.
